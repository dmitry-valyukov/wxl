# Декларативный синтаксис

**Задача:** дать возможность описывать графический интерфейс одним
выражением C++ — иерархией компонентов, их свойствами, обработчиками событий
и реактивными привязками — без «текущего объекта», на который присваивание
могло бы попасть по ошибке.

Пример декларативного описания полей ввода и вывода из демонстрационного
проекта `samples/Quadratic/main.cpp`. Здесь `input` и `output` — пресеты,
`eq` — объект модели с полями типа `wxl::core::observable`; `wxl::BindInput`
записывает в поле модели то, что вводят в контрол, а `wxl::BindOutput`
показывает поле в контроле:

```cpp
NumberBox {
    input,
    placeholderText = u"a",
    intermediateValue = BindInput {eq.a},
},
// …
TextBox {
    output,
    text = BindOutput {eq.D},
},
```

## Принципы реализации и компоненты

Выражение присваивания внутри инициализатора (например, `content = u"OK"`)
не изменяет состояние немедленно, а конструирует легковесный объект
отложенной операции (`member.h`). Вариадический конструктор целевого класса
применяет весь переданный набор аргументов к только что созданному
компоненту в порядке их записи.

На основе этого принципа построены остальные элементы декларативного
синтаксиса:

- **Теги свойств и событий.** Для каждого свойства, события, коллекции и
  присоединённого свойства генератор создаёт тег в файле `Members.h`.
  Присоединённое свойство записывается на дочернем элементе, а применяется
  статической логикой родительского контейнера: например,
  `Button { row = 1, column = 2 }` внутри контейнера `Grid`.
- **Безымянные аргументы.** Распределяются по своим типам. Строка попадает в
  текст или содержимое контрола, а вложенный элемент — в коллекцию, которую
  метаданные называют коллекцией содержимого (`ContentPropertyAttribute`:
  `Panel.Children`, `ItemsControl.Items`). Значение перечисления несёт свой
  тег (`hAlign.center`, `orientation.horizontal`). Когда тип аргумента не
  определяет свойство однозначно (три разных свойства принимают
  `Thickness`, десятки — `double`), значение помечается тегом своего
  свойства: `Margin {16, 0}`, `Padding {8}`, `FontWeight {600}`.
- **`wxl::Preset` (пресеты).** Именованный набор аргументов конструктора.
  Пресет не привязан к конкретному типу: он применим к любому компоненту, у
  которого есть названные в нём члены, и проверяется в точке использования.
  Пресет из констант сам является константой и ничего не исполняет при
  запуске. Пресеты можно вкладывать друг в друга.
- **`wxl::Template<T>` (шаблоны).** Описание объекта, экземпляр которого
  создаётся в момент применения, а не в точке объявления. Шаблоны нужны там,
  где объект невозможно создать на месте: в константе на уровне пространства
  имён (до запуска среды выполнения ни один объект WinRT не живёт) и в общем
  пресете (один дочерний элемент нельзя добавить двум родителям).
- **`wxl::Apply { target, … }`.** Применяет тот же набор аргументов к уже
  существующему объекту.
- **Повторители элементов.** Лямбды вида `[](repeat<20> i) { … }` и
  `[](iterate<u"789"> key) { … }` строят дочерние компоненты по числу или по
  значениям, записанным в типе параметра. Благодаря `constexpr` и
  параметрам шаблонов константные пресеты и повторители элементов (по числу
  или строковому литералу) разворачиваются ещё при компиляции.
- **Ресурсы темы.** Пути к ресурсам темы записываются цепочками:
  `styles.TextBlock.Subtitle` или `brushes.Card.BackgroundFillColor.Default`.
  Кисть, заданная путём, следует за сменой темы. Цвета (`rgb(…)` и
  `rgba(…)`) вычисляются при компиляции.
- **Понятные ошибки компиляции.** Передаваемые типы проверяет компилятор:
  неподходящий аргумент отвергается на этапе сборки с помощью
  `static_assert`, который выводит подсказку по исправлению. Вместо
  сообщения «нет подходящей перегрузки» подсказка называет, что написать
  вместо аргумента (`text = ...` или тег `Margin{20}`). Тот же словарь,
  разложенный по классам, находится в `schema.h` (`schema::Button::content`):
  по нему подсказывает IDE, и он не даёт записать член одного класса на
  другой.

## Особенности и ограничения

Порядок аргументов имеет значение: они применяются слева направо.
Например, в `samples/HelloHere/main.cpp` строка разметки `HtmlBlock` стоит
последней, потому что размер тега `<sub>` считается от уже заданного кегля.

Любой контрол внутри декларативного выражения — временный объект. Если
обёртку компонента нужно держать после выражения, её заводят отдельной
переменной до него. Пресет не может нести живой объект — для этого служит
`wxl::Template`. Компиляция файла с разметкой — это компиляция шаблонов C++.
