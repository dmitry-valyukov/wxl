# Текст и разметка

## Текст

Текст в `wxl.core` (`unicode.ixx`) — это проверенные виды `wxl::core::u8_view`
и `wxl::core::u16_view` и владеющие `wxl::core::u8_text` и
`wxl::core::u16_text`. Текст извне проверяется один раз, на входе
(`checked()`); `assume_valid()` — там, где записано, почему проверка не нужна.
Границы букв — графемные кластеры по таблице Unicode
(`wxl::core::unicode::grapheme_breaker`, `next_grapheme_boundary`,
`floor_grapheme_boundary`); по ней же `is_letter` — буква ли кодовая точка
(общая категория L: Lu, Ll, Lt, Lm, Lo).

**Таблица графемных кластеров.** Таблицу свойств Unicode
`wxl.core/src/grapheme_data.inc` пишет `wxl.core/tools/gen-grapheme-table.py` —
одна версия Unicode на оба ответа. Файл сгенерирован и в сборке не
пересоздаётся: данные меняются раз в год, с выходом новой версии Unicode.
Генератор написан на Python, интерпретатор и зависимости поднимает
[uv](https://docs.astral.sh/uv/) по метаданным в шапке скрипта. Из корня
дерева:

```
uv run wxl.core/tools/gen-grapheme-table.py
```

Скрипт скачивает с unicode.org пять файлов закреплённой версии
(`UNICODE_VERSION` в нём самом; кэш — `build/unicode/<версия>`) и пишет два:
таблицу и официальный тест `wxl.core/tests/data/GraphemeBreakTest.txt` той же
версии. Переход на новую версию Unicode: поднять `UNICODE_VERSION`, запустить
скрипт и прогнать `wxl.core.tests` — тест проверяет таблицу вместе с правилами
на всех случаях файла, пробы `is_letter` — бит буквы.

## Форматирование

`wxl.fmt` — `wxl::core::text_builder` и `format` поверх fmt, которая
собирается модулем `import fmt;` из своих исходников; ядро от внешнего кода
не зависит. Подробно — [`wxl.fmt`](../wxl.fmt/README.md) и
[замеры](../wxl.fmt/doc/fmt.md).

## Читатели XML и JSON

`wxl::xml`, `wxl::json` — буфер переходит читателю и проверяется целиком,
дерево — виды в него, узлы — в арене поверх пула потока. JSON читается с
комментариями всегда: на нём написаны профили генератора.

## Разметка чужих сообщений

`wxl.html`, `wxl.bb`, `wxl.rsdn` — разметка чужих сообщений (форумы, чаты) без
WebView. Разбор терпит любой мусор: неизвестный тег исчезает, его текст
остаётся. Три разборщика строят одно дерево, его показывают `wxl::HtmlBlock`,
`wxl::BbBlock` и `wxl::RsdnBlock` через `RichTextBlock`. Устройство —
[заметка о `wxl.html`](../wxl.html/design.md).

`wxl.highlight` — подсветка кода для 31 языка по таблицам: у комментария —
открывающая и закрывающая последовательности, у строки — кавычка и
экранирование, у ключевого слова — границы. Регулярных выражений нет.

## Журнал

`wxl.logging` — журнал, где строка — один вызов: сообщение ниже уровня стоит
одного сравнения, форматная строка проверяется при компиляции, асинхронная
половина пишет из своего потока.
