# Настройка среды разработки

## Поддержка IntelliSense в VS Code для модулей C++

**Конфигурация.** Настройка дерева записывает в каталог сборки базу команд
компиляции `compile_commands.json` (`CMAKE_EXPORT_COMPILE_COMMANDS` в корневом
`CMakeLists.txt`): для пресета `x64` это `build/x64/compile_commands.json`.
Расширение C/C++ берёт из неё ключи компиляции каждого файла, если путь к
базе указан в `.vscode/c_cpp_properties.json` (свойство `compileCommands`)
или в параметре `C_Cpp.default.compileCommands`.

**Ограничение.** Расширение C/C++ от Microsoft считывает скомпилированные
интерфейсы модулей (`.ifc`) только при явной передаче флага
`/reference <имя_модуля>=<путь>`. CMake передаёт эти ключи во внутренних
файлах ответов `*.obj.modmap`, оставляя в `compile_commands.json` лишь ссылку
вида `@path/to/file.modmap`, которую `cpptools` обрабатывать не умеет.
Провайдер конфигурации CMake Tools данные ключи компилятора также не
передаёт. Поэтому импорт партиций модулей (`import :partition;`) редактор
может подсвечивать как синтаксическую ошибку; на сборку это не влияет.
