# Окно, композиция, эффекты

## Точка входа

`wWinMain` живёт в `wxl.ui` (`launch.h`), и цель `wxl::ui` передаёт
исполняемому файлу `/ENTRY:wWinMainCRTStartup`. Библиотека поднимает Windows
App Runtime нужного канала (`bootstrap.cpp`), STA-поток с его пулом, объект
приложения XAML и ресурсы контролов — и только потом вызывает
`wxl_launched()`. Приложение пишет одну функцию: ни `wWinMain`, ни загрузчика
Windows App Runtime, ни наследника `Application`.

## Два окна

`wxl::Window` — сгенерированная обёртка `Microsoft.UI.Xaml.Window` с
синтетическими `minSize` и `placement`. `wxl::CompositionWindow`
(`CompositionWindow.h`) — своё окно верхнего уровня, созданное с
`WS_EX_NOREDIRECTIONBITMAP`: поверхности перенаправления у него нет, и при
быстрой растяжке за угол в просвете нечему белеть. У него два слоя. Сцена —
визуалы своего композитора `Microsoft.UI.Composition`: фон цветом или
картинкой (картинку держит кэш текстур Win2D) и визуалы, которые приложение
рисует само; они меняют размер синхронно в `WM_SIZE` и держатся за рамку без
отставания. Над сценой — прозрачный остров XAML (`DesktopWindowXamlSource`) во
всё окно, со всем, чем силён WinUI. Строка заголовка пишется обычным
элементом, масштаб острова целиком — `wxl::ZoomEffect`, просьбу закрыть окно
обработчик `onClosing` может отклонить. Рисовать Direct2D в поверхность
композитора — `wxl::DrawingSurface`.

## Эффекты

Эффекты пишутся в скобках элемента (или окна), как свойства, и делаются
композитором рядом с тем, что рисует XAML. Композитора при построении
элемента ещё нет — элемент не принадлежит окну, — поэтому эффект
присоединяется позже, когда у элемента появится свой визуал
(`wxl::HaloEffect` — в первых кадрах, `wxl::GlassEffect` — по `Loaded`).

| Эффект | Что делает |
| --- | --- |
| `wxl::HaloEffect` | свечение вокруг глифов: `DropShadow` без смещения по альфа-маске текста, картинки или фигуры |
| `wxl::BevelEffect` | кант: один цвет по верху и левому краю, другой по низу и правому — `ShapeVisual` поверх элемента |
| `wxl::MagnifyEffect` | рост (или сжатие) элемента под указателем, за фиксированное время, а не по расстоянию до центра |
| `wxl::GlassEffect` | матовое стекло под элементом: размытое и тонированное то, что за ним, — и в острове, и на сцене окна |
| `wxl::Button3DEffect` | кнопка как предмет под лампой: грани, обводка и блики выводятся из цвета материала и цвета знаков |
| `wxl::GaussianBlurEffect` | свечение вокруг глифов с затуханием на выбор приложения |
| `wxl::RevealEffect` | свет за указателем: пятно на элементе под ним и свечение краёв соседних |
| `wxl::FocusEffect` | фокус с клавиатуры, показанный в стиле окна, а не системной рамкой; вешается на окно |
| `wxl::ZoomEffect` | масштаб всего острова с клавиатуры и колеса; вешается на `wxl::CompositionWindow` |

Исходники эффектов — `wxl.ui/src/<Имя>.h`. Каталог эффектов, готовых и
задуманных, — [«Эффекты современного GUI»](../wxl.ui/doc/effects-catalog.md).

## Цена и границы

Окно без поверхности перенаправления насквозь прозрачно, пока сцена ничего не
нарисовала: фон ставится до показа окна. Тяжёлое не дублируется: фоновая
картинка — один визуал на сцене, а не визуал и копия в дереве XAML. Без DLL
Win2D рядом с исполняемым файлом конструктор `wxl::CompositionWindow` падает:
общий `CanvasDevice` строится в нём. Что кладёт DLL рядом — функции CMake на
странице [«Сборка и проверки»](building.md).
