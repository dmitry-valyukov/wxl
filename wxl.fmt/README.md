# wxl.fmt

Собственный буфер и построитель текста поверх библиотеки
[fmt](https://github.com/fmtlib/fmt): `text_buffer`, `text_builder` и функция
`format` — текст для интерфейса одним вызовом. Модуль для подключения:
`import wxl.fmt;`, цель сборки: `wxl::fmt`. Устройство, замеры и сборка `fmt`
модулем — [docs/fmt.md](../docs/fmt.md).
