# async

Асинхронная подсистема: корутины `task`, диспетчер
`sta_loop` с неблокирующим файловым вводом-выводом, отмена операций,
lock-free очереди и каналы, `future`, потоки и компонентная модель. Область
модуля `wxl.core`: `import wxl.core;`, цель сборки: `wxl::core`. Устройство —
[docs/async.md](../../../docs/async.md) и [docs/lockfree.md](../../../docs/lockfree.md).
