# json

Читатель JSON той же конструкции, что читатель XML: буфер целиком, дерево
видами, узлы в арене. Комментарии читаются всегда: на этом формате написаны
профили генератора `winui-srcgen`. Область модуля `wxl.core`: `import wxl.core;`,
цель сборки: `wxl::core`. Устройство — [docs/text.md](../../../docs/text.md).
