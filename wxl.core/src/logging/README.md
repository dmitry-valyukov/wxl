# logging

Журнал, где строка — один вызов: сообщение ниже уровня стоит одного
сравнения, форматная строка проверяется на этапе компиляции, асинхронная
половина пишет из собственного потока. Область модуля `wxl.core`:
`import wxl.core;`, цель сборки: `wxl::core`. Устройство —
[docs/text.md](../../../docs/text.md).
