Таблица тегами \[t] (скобка экранирована, иначе это был бы тег):
[t]
[tr][th]Тег[/th][th]Что делает[/th][/tr]
[tr][td][tt]t[/tt][/td][td]Таблица с рамкой; заголовок ячейки — жирный и по центру, а длинный текст в широкой колонке переносится, пока включён перенос.[/td][/tr]
[tr][td][tt]hr[/tt][/td][td]Линейка во всю ширину текста над этой таблицей.[/td][/tr]
[/t]

Код с языковым тегом и подсветкой:
[c#]
// Комментарий
var x = items[i];
return x > 0 ? "plus" : @"minus ""quoted""";
[/c#]

Тот же язык значением тега:
[code=pascal]
{ Pascal без учёта регистра }
BEGIN WriteLn('it''s'); End.
[/code]

Языки форума, которых у RsdnFormatter не было:
[js]
const s = `итого: ${count}`;  // шаблонная строка целиком
[/js]
[go]
func main() { print(`сырая
строка`) } // Go
[/go]

Тега [lua] у форума нет — так он и остаётся текстом, а значением тега язык
работает:
[code=lua]
--[[ длинный комментарий ]]
local t = [[длинная строка]] -- хвост
[/code]
[code=bash]
echo ${name#префикс} $# # решётка открывает комментарий после пробела
[/code]
