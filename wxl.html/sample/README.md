# Образцы для глазной проверки

Адаптированные HTML-строки и ресурсы, которыми `HtmlBlock` проверяется
визуально — в дополнение к юнит-тестам ядра в `tests/`, которые сверяют
сериализованный DOM, но не картинку. Каждый файл — одно окно будущего
смотрового приложения: открыл, посмотрел, сравнил с ожиданием, описанным
в комментарии в начале файла.

Файлы намеренно содержат и корректную разметку, и мусор: политика парсера
«текст священен, теги — нет» проверяется только на мусоре.
