Gaussian Blur Effect — ореол с управляемым спадом

Тот же ореол вокруг глифов, что и у HaloEffect, но нарисованный не тенью, а графом эффектов: альфа глифов размывается по Гауссу, затем возводится в степень gamma, и этой альфой вырезается заливка цветом. Гамма — это форма спада: 1 — размытие как есть, меньше единицы — середина спада поднимается и ореол становится плотным до самого края, больше единицы — остаётся лишь слабая корона.

TextBlock {
    u"7",
    GaussianBlurEffect { color = rgb(0, 0, 0), blurRadius = 3.0f, gamma = 0.5 },
}

Зачем он, если есть HaloEffect: у DropShadow плотность не поднять выше opacity = 1, а размытие растягивает эту альфу по всему ореолу. Тугая тёмная обводка цифры на клавише требовала двух ореолов один на другом. Здесь то же даёт один эффект с gamma = 0.5.

zIndex хранится в Visual.Properties слоя, потому что у самого Visual порядкового номера нет — только место в коллекции детей.

Граф собирается из эффектов Win2D (Microsoft.Graphics.Canvas.Effects), которые дерево и так линкует; размер слоя — элемент плюс радиус размытия по краям, чтобы ореол не обрезался на границе элемента.
