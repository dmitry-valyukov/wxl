Halo Effect — свечение вокруг глифов

Ореол — это тень с нулевым смещением, вырезанная по альфе разложенных глифов. Своего цвета, радиуса и нулевого смещения у ThemeShadow фреймворка нет — это тень высоты, а не света, — поэтому ореол делается композицией, а не деревом XAML.

TextBlock {
    u"0",
    fontSize = 48,
    HaloEffect { color = rgb(92, 138, 32), blurRadius = 14.0f },
}

Композитора в этот момент взять неоткуда: элемент ещё строится и никакому окну не принадлежит. Эффект вместо этого ждёт кадра (CompositionTarget.Rendering), пока XAML не сделает элементу собственный дочерний визуал, и берёт композитора уже у него; тогда же берётся и альфа глифов — раньше глифов нет. Кадр, а не событие элемента: о постройке своих композиционных детей XAML ничего не объявляет, а на открывшемся окне, которого никто не трогал, LayoutUpdated больше не приходит.

Дождавшись, ореол встаёт среди слоёв элемента по zIndex. Теги — те же, что у свойств самой тени (DropShadow), плюс zIndex. Объекты композиции у каждого элемента свои. Присоединить эффект можно к чему угодно, умеющему отдать альфу своих глифов: requires { element.getAlphaMask(); }.

Ореолы складываются: два на одном элементе дают тугое ядро и широкий разлёт — так сделан светодиодный индикатор ниже. Когда нужен один плотный ореол, а не два, есть GaussianBlurEffect с гаммой спада.
