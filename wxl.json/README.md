# wxl.json

Читатель JSON той же конструкции, что `wxl.xml`: буфер целиком, дерево
видами, узлы в арене. Комментарии читаются всегда: на этом формате написаны
профили генератора `winui-srcgen`. Модуль для подключения: `import wxl.json;`,
цель сборки: `wxl::json`. Устройство — [docs/text.md](../docs/text.md).
