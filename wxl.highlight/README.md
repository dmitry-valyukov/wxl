# wxl.highlight

Подсветка кода для 31 языка по статическим таблицам правил: комментарии по
открывающим и закрывающим последовательностям, строки по кавычкам с учётом
экранирования, ключевые слова по границам слов; регулярных выражений нет.
Модуль для подключения: `import wxl.highlight;`, цель сборки:
`wxl::highlight`. Обзор — [docs/text.md](../docs/text.md).
