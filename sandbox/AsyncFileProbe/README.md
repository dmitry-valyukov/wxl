# AsyncFileProbe: файл через wxl.async в настоящем приложении

Проба отвечает на один вопрос: работает ли `async_file` в приложении wxl без
всякой настройки — то есть под циклом, который крутит `Application::Start`, с
петлёй, запущенной самой библиотекой.

В `wxl_launched` поднимается окно и стартует корутина. Она открывает
собственный исполняемый файл, читает его до конца кусками по 4 КБ, спрашивает
размер и через `async_directory::exists` проверяет, что её каталог на месте. Открытие и `exists` уходят в
пул потоков системы и возвращаются через очередь диспетчера потока, чтения
идут через порт завершения. После каждого `co_await` проба сверяет, что
продолжение исполняется на потоке окна.

Результат пишется в `async-file-probe.txt` рядом с пробой, после чего она
завершается сама.

Запуск: `sandbox.async-file-probe`.
