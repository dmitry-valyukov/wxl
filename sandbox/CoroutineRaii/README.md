# CoroutineRaii: работает ли RAII в теле корутины

Проба отвечает на один вопрос: выполняются ли деструкторы локальных объектов
тела корутины — и когда её возобновляют до конца, и когда приостановленный
кадр сносят `coroutine_handle::destroy()`.

Повод — два красных теста в `wxl.async` на корутину, которая сама себе хозяин:
отпускает ли она локальный объект тела, когда тело кончилось и когда кадр снесли, —
в Release оба видели, что не отпущен.

Проба намеренно ни с чем не связана: ни библиотеки дерева, ни его модулей,
только `<coroutine>` и консольный вывод. Так разделяются два объяснения —
поведение компилятора и что-то наше. Формы корутин две: «сам себе хозяин» (оба
конца `suspend_never`) и «с владельцем» (`final_suspend` — `suspend_always`);
третий случай — свой `operator new` у промиса, который заодно показывает,
выделялся ли кадр вообще.

Запуск: `sandbox.coroutine-raii`, код возврата — число провалившихся проверок.
