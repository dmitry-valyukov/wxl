# ModalLoopProbe: завершения петли под модальным циклом

Проба отвечает на один вопрос: доходят ли завершения `sta_loop` до корутин,
пока продолжение другой корутины стоит в модальном цикле.

Первая корутина читает собственный исполняемый файл и в продолжении первого
чтения, то есть прямо внутри разбора петли, открывает `MessageBox` без
окна-владельца. Перед этим она запускает вторую корутину, которая читает тот
же файл до конца и считает чтения, пришедшие, пока окно сообщения открыто.
Отдельный поток закрывает окно через полторы секунды.

Что проверяется: хук простоя потока (`WH_FOREGROUNDIDLE`), который ставит
`sta_loop::start_dispatched()`, видит простой модального цикла и постит разбор
в очередь диспетчера, а та доставляет его в модальный цикл. У окна сообщения
нет владельца, так что `WM_ENTERIDLE` окна тут не участвует: проверяется именно
хук. Хук зовётся только у потока на переднем плане, поэтому окно пробы должно
быть активным.

Результат пишется в `modal-loop-probe.txt` рядом с пробой: сколько чтений
пришло под открытым окном и вердикт.

Запуск: `sandbox.modal-loop-probe`.
