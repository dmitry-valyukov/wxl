# ApcProbe: доходят ли APC до потока GUI

Проба отвечает на один вопрос: исполняет ли цикл сообщений, который крутит
`Application::Start`, пользовательские APC — то есть можно ли начать
`ReadFileEx` прямо в потоке GUI и получить его completion routine там же.

Окно wxl поднимается и простаивает. В `wxl_launched` на потоке GUI начинается
`ReadFileEx` собственного исполняемого файла, а второй поток трижды, раз в
секунду, ставит потоку GUI `QueueUserAPC`. Через пять секунд проба пишет, что
исполнилось, в `apc-probe.txt` рядом с собой и завершается.

Ответ на Windows 11 26200 и Windows App SDK 2.x: ничего не исполняется. Вызовы
проходят успешно, но ни completion routine, ни одна из трёх APC до потока не
доходят — цикл не ждёт в alertable-состоянии.

Запуск: `sandbox.apc-probe`, результат — в `apc-probe.txt` в каталоге запуска.
